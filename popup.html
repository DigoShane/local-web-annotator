How to use

  1. Open the instruction drawer/panel on the website.
  2. Click Start highlighting.
  3. Select text. It highlights automatically.
  4. Click a highlight to add a comment or delete it.
  5. To add a graphic comment, select text and then click a shape in the floating toolbar. Drag the graphic to reposition it relative to the selected text.
